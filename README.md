# 荆棘誓约 · 黑棘森林（3D 森林动作战斗 Demo）

基于 HTML5 + Three.js（CDN 动态加载，零本地依赖库）构建的 3D 森林动作战斗 Demo，由 **GPT-6.2 Astra (Ultra)** 在 **Codex CLI (`codex`)** 中生成。

## 🌐 在线试玩链接 (GitHub Pages)

- **在线试玩**：<https://chan-yuu.github.io/thornbound-gpt-6.2-astra-ultra/>

## 🎮 核心战斗机制

- **森林战场与敌人**：黑棘森林战场，敌人包含**半兽人**与**半兽人统领（Boss）**。
- **近身积怒 → 怒气点（最多 3 点）**：通过近战攻击积攒怒气槽（`0 / 100`）；每蓄满 `100` 怒气自动激活 `1` 个怒气点，最多储存 `3` 点，所有技能消耗怒气点释放。
- **`1` 怒气点 · 突进斩（按键 `1`）**：冲向前方敌人，挥剑近身重击。
- **`2` 怒气点 · 回旋飞盾（按键 `2`）**：远程投掷盾牌，依次撞击附近最多 `2` 名敌人后飞回手中。
- **`3` 怒气点 · 旋风斩（按键 `3`）**：持剑高速旋转，连续斩击身边敌人。

## ⌨️ 操作说明

| 按键 | 动作 |
| --- | --- |
| `W A S D` / 方向键 | 移动 |
| `鼠标左键` / `J` | 挥剑（按住可连续攻击） |
| `鼠标右键` / `K` | 按住举盾格挡 |
| `Space` | 闪避 |
| `1` / `2` / `3` | 施放 1 / 2 / 3 怒气点技能 |
| `Esc` | 暂停 / 继续 |
